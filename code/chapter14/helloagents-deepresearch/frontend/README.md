# M1：前端多研究管理

左侧研究列表支持查看不同研究，以及单独取消运行或等待中的研究。
列表显示主题、研究 ID、创建时间、状态、子任务进度和报告是否生成。

- “开始新研究”打开输入界面，原研究继续在后台运行；提交按钮仅在登记请求期间禁用。
- 输入页也提供已有研究列表，可以返回任何研究。
- 每个研究分别保存任务选择、内容页签和研究流程折叠状态；切换查看不会取消研究。
- 当前研究使用 SSE 实时显示，列表每 3 秒查询状态。重新查看时读取快照，再从其事件序号接收增量，避免重复总结。
- 连接异常会重新同步；关闭页面只断开订阅，取消必须使用取消按钮。
- 页面刷新可重新读取同一后端进程中的列表，并尝试重新打开上次查看的研究。
- 后端重启会清空内存记录；不会自动重建或续跑研究。前端不持久化研究正文。
- 研究运行/等待满额时显示提交失败提示，保留输入和已有研究。

本阶段沿用原有 Markdown、任务清单与最终报告切换、任务详情页签，工具结果仍保留 900 字显示限制。
后端研究逻辑及提示词未在 M1 修改。

## 简单验证

使用 Linux Node 24：`node --test tests/research-management.test.mjs`，以及 `npm run build`。
测试使用内存事件和模拟响应，不创建真实研究。

手动检查：连续提交多个主题，切换查看并取消其中一项；确认其他研究继续运行；
在任务总结输出中切换后再返回，确认内容不重复；刷新页面检查列表与报告恢复。
